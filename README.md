# JUDGE90

Jリーグの成績からtoto対象13試合を予測する静的ダッシュボードです。

## 開発・テスト

Node.js 20以上（Actionsは22）を使用します。

```sh
npm ci --ignore-scripts
npm test
```

## データ更新

```sh
npm run update
```

公式の通常totoを取得し、開催回・商品・番号1〜13・公式日程を検証してから予測と買い目を生成します。更新失敗時は前回の予測を保持し、状態とエラーを記録します。チームIDはJUDGE90独自ID、所属リーグはシーズンの日程から判定します。

GitHub Actionsは毎週土曜9:17日本時間に更新します。手動実行も可能です。フィーチャーブランチから公開更新は実行しません。mainへのマージと本番反映は所有者の承認が必要です。

- [第1段階の修復内容・利用条件・検証上の制約](docs/stage1.md)
- [第2段階以降の優先順位](docs/roadmap.md)

現行モデルは固定重み方式です。判定スコアは実際の的中確率ではありません。天気は取得可能な場合のみ表示し、予測確率には未反映です。予測は当選や収益を保証しません。
