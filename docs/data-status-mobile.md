## 使用データの明示

現行v2.1は今季成績、得失点、直近フォーム、ホーム/アウェイ成績、利用できるH2Hを使用する。天気、会場所在地、負傷、スタメンは予測に未使用。会場名・キックオフは参考表示用。ホーム/アウェイ別成績を使うことと、会場所在地を特徴量に使うことは別である。

予測JSONへ使用データの宣言と会場・開始時刻を追加。更新状態JSONへ13試合のデータ品質一覧と参考項目の警告区分を追加する。天気取得が停止しても既知の座標・会場情報を保持する。未知のモデルについて天気使用を勝手に未使用と断定せず、使用宣言を確認する。天気を必須入力にする将来モデルでは、欠損時に公開検証を止めるガードを追加した。

同じ入力で予測を再生成し、13試合の1/0/2確率、本命、判定スコアが全件同一であることを確認した。予測式は変更していない。
