# 次の研究課題：引き分け確率と検出能力

設定日：2026-10-25 JST。本番モデルは2.1を維持し、現在登録済みの候補・確認期間を途中変更しない。

## 調べる順序

1. J1/J2/J3別に引き分けの実際の頻度、予測確率帯、引き分けBrier、適合率・再現率を記録する。引き分け本命がない場合の適合率は未評価とし、実引き分けがある場合の再現率0%とは区別する。
2. 得点が少ない試合・実力が近い試合でPoisson/Dixon-Colesの誤差を分ける。低スコア補正、ホーム優位、昇降格・リーグ間の差を調べる。利用できない先発・天気情報を推測で埋めない。
3. 学習期間内の時系列予測だけを使い、温度補正と引き分けバイアスに加え、リーグ別の部分プーリングを検討する。小標本でリーグごとの補正を自由に増やさない。
4. 新しい校正候補は未使用の将来期間を別登録する。2025年を新しいモデル選択に使わず、現行確認試験（2026-11〜2027-05）を見て有利なしきい値を探さない。

## 採用の条件

引き分けを多く選ぶこと自体を目標にしない。LogLoss・全体Brier・引き分けBrierを悪化させず、未使用期間で引き分けの検出と適合率がどう変わるかを示す。試合日ごとの依存、リーグごとの標本数、検定を繰り返す影響も扱う。主判定は確率指標と事前登録した条件による。結果が改善しなければ現行モデルを維持する。

## 現在の制約

2024年の開発比較では、校正・アンサンブルがPoisson単独を上回らず、引き分け検出の改善は未確認。今回の第1665回の部分照合では0-0と2-2も見つかったが、5試合だけで改善手法を選ばない。配信証跡のない旧予測を新しい実運用実績として扱わない。
