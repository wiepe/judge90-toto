# 継続評価の証跡と指標

予測生成・Pages配信・結果取得を別々に記録する。`data/deliveries/` に保存する配信完了記録が、予測本文のSHA256・dataset_idと一致し、販売締切とキックオフより前である場合のみ `data/evaluation.json` の実運用集計対象とする。古いデータを後から配信済みとみなさない。

3時間ごとの既存更新の結果照合に続けて、的中率・自然対数LogLoss・3クラスBrier（各クラスの二乗誤差の合計）・引き分け適合率/再現率・引き分けBrier・確率帯別の実引き分け率を更新する。分母が0の場合は0%ではなくnull（未評価）。保存された丸め済み確率は許容誤差0.002以内で再正規化し、不正値は除外理由を記録する。LogLoss下限は1e-15。

同一開催回は締切前に公開を確認できる最新予測を使う。複数開催回に同一試合が入る場合も試合ID（リーグ・日付・両チームID）で重複除外。全体・リーグ別・日ごとの累積推移を記録し、変更があった評価内容は `data/evaluation-history/` に追記する。結果の訂正は新しい履歴になり、元の記録を削除しない。

Pages配信記録は配信後の別コミットで保存する。公開サイトへの反映は次の通常更新になる場合がある。記録コミットに失敗した場合もActions artifactには残るが、証跡がリポジトリにない予測を実運用評価へ算入しない。既存のPages配信方式・予測更新・失敗時の正常データ保持を維持する。

試合当日のスコアは確定扱いせず翌日以降に照合する。これはJリーグの試合結果との照合で、toto公式の中止・みなし的中・払戻裁定や賞金の計算ではない。過去の研究用バックテストと、この配信証跡付きの成績を分けて表示する。

検証：新規4件（指標の手計算、配信・締切・試合日制約、リーグ別集計、訂正と冪等性）。既存51件を含むNode55件、actionlint。実運用の配信証跡付き確定試合はまだ0件であり、精度向上を示す結果は得られていない。
