# 第2段階：複数シーズンの比較検証

## 結論

**本番モデルは現行のまま維持する。** 2024年で選択したPoisson候補は2025年の的中率を44.82%から46.05%へ上げたが、LogLossの相対改善は0.64%で事前基準1%に届かず、日付単位のペア・ブートストラップ95%区間も0を含んだ。本番の予測式・自動更新ワークフロー・公開データ・トップページを変更していない。

Eloは2025年の的中率48.33%と良好だったが、2024年に選ばれた候補ではない。最終評価の結果を見てEloへ選び直さない。将来データによる独立した評価が必要。

## 事前に固定した比較方法

`research/protocol.json` を結果評価より先にコミットした。

- 初期学習：2022〜2023年。
- 設定選択：2024年。リーグごとのLogLoss平均で候補を1つ選ぶ。
- 最終評価：2025年。選択した候補をここで選び直さない。
- 同日の予測をすべて出した後で、その日の結果を取り込む。キックオフの同日内の順序も使わない。
- 得点モデルの再学習は月単位。その月の初日より前の試合結果だけを使う。評価期間中もそれまでに終了した結果で更新する、事前に定めたオンライン運用の再現である。
- 傷病・スタメン・天気・投票率・順位の完成シーズン値などは入力しない。
- 採用条件は、現行式とリーグ平均に対するLogLoss/Brier改善、的中率の非悪化、引き分け再現率改善、リーグ別の大幅非悪化、最低試合数、95%区間での改善確認。条件を満たさなければ現行を維持。

2025年の結果は今回の設定選択に未使用だが、2026年から見た過去データであり、将来の実運用テストではない。公開・訂正時刻の当時のスナップショットはないため、「当時利用可能だった版そのもの」の完全な証明はできない。この制約を隠さない。

## 比較するモデル

- **ホーム固定**：すべて1。的中率の基準。確率0のLogLossは計算上1e-15へ丸めて保存するため、確率品質の比較表では参考外とする。
- **リーグ平均**：予測日より前のリーグ別の1/0/2頻度。少数例の初期化は固定事前分布。
- **現行式**：v2.1の重みと引き分け式を再現。直近5試合、会場別成績、シーズン成績、H2Hを使う。H2Hは整備した2022年以降のリーグ戦のみ。2004年以降のカップ戦も使う本番モデルの公開予測実績そのものではない。
- **Elo**：相手レーティングで勝敗を補正し、ホーム補正とDavidson型の引き分け確率を付加。各リーグ内でレーティングを保持。検証した設定では0は本命になっていない。
- **Poisson**：チーム攻撃力・守備力、リーグ別得点水準・ホーム補正を過去得点から推定。時間減衰と正則化を使用。
- **Dixon–Coles**：Poissonの低得点（0-0/0-1/1-0/1-1）へ相関補正を追加し、係数も過去データから推定。正確な勾配と確率の非負性・総和を検査する。

Poisson/Dixon–Colesは低得点の拮抗した試合で0が本命になり得る。全モデルで最高確率を本命とし、引き分け数を増やすためだけの事後的なしきい値調整はしない。新規・昇格クラブの十分な同リーグ履歴がない場合は平均的な強さを事前値とする。昇降格によるリーグ間実力移転や休養日数を追加した効果は、今回まだ検証していない。

## 2025年・1,140試合の最終評価

| モデル | 的中数 | 的中率 | LogLoss ↓ | Brier ↓ | 引き分け適合率 | 引き分け再現率 |
|---|---:|---:|---:|---:|---:|---:|
| ホーム固定 | 489 | 42.89% | 参考外 | 1.1421 | 該当なし | 0.00% |
| リーグ平均 | 489 | 42.89% | 1.0759 | 0.6514 | 該当なし | 0.00% |
| 現行式 | 511 | 44.82% | 1.0646 | 0.6421 | 該当なし | 0.00% |
| Elo | 551 | 48.33% | 1.0495 | 0.6314 | 該当なし | 0.00% |
| **Poisson（2024年で選択）** | **525** | **46.05%** | **1.0578** | **0.6374** | **26.67%** | **1.37%** |
| Dixon–Coles | 528 | 46.32% | 1.0575 | 0.6372 | 33.33% | 1.37% |

引き分けの実数は291。Poissonは15試合を0本命とし4試合的中、Dixon–Colesは12試合を0本命とし4試合的中した。「0を選べない」構造は候補モデルで解消できたが、引き分け検出能力は十分ではない。

選択したPoissonの現行式との差：的中率 **+1.23ポイント（14試合）**、LogLoss **-0.00677（相対0.64%改善）**、Brier **-0.00474**。LogLoss差の95%区間は **[-0.02354, +0.00784]**。0を含むため改善を確定しない。再標本化は同日試合をまとめた日付ブロック単位、2,000回、固定シード。週をまたぐ依存や1シーズンだけの評価など、残る不確かさもある。

| リーグ（各380試合） | 現行式の的中率 | 選択Poissonの的中率 | 現行式LogLoss | 選択Poisson LogLoss |
|---|---:|---:|---:|---:|
| J1 | 43.95% | 47.37% | 1.0603 | 1.0471 |
| J2 | 42.89% | 43.16% | 1.0712 | 1.0774 |
| J3 | 47.63% | 47.63% | 1.0622 | 1.0489 |

J2では確率評価が悪化している点も明記する。以前の290試合の検証とは年度・試合・H2H条件が違うため、その的中率との差を精度改善として扱わない。

## 13試合・予算別の計算

`scripts/lib/portfolio.mjs` は、予算上限内でシングル・ダブル・トリプルを組み合わせ、独立仮定で全13試合をカバーする推定確率が最大となる候補を動的計画法で求める。各試合の本命・2択は予測確率の上位から選ぶ。最大支出は既定100万円（設定可能）、1通り100円。賞金・期待収益は `null` とし、推測しない。購入処理は実装しない。

2025年の最初の検証予測13試合による、**実際のtoto開催回ではない計算例**：

| 予算上限 | 計算上の購入額 | 組合せ | 全13をカバーする独立仮定の推定 |
|---|---:|---:|---:|
| 100円 | 100円 | 1 | 0.00412% |
| 1,000円 | 900円 | 9 | 0.02601% |
| 5,000円 | 4,800円 | 48 | 0.11029% |
| 10,000円 | 9,600円 | 96 | 0.18320% |

これは真の当選確率・回収率ではない。試合間の依存、確率の推定誤差、toto対象試合との違いがある。表示は研究用に限定し、本番の買い目生成へ自動接続していない。

## 実行・再現

```sh
npm ci --ignore-scripts
npm test
python -m pip install -r research/requirements.txt
python -m unittest discover -s tests/research -v
OPENBLAS_NUM_THREADS=1 python research/evaluate.py
```

取得を再実行する場合：`node scripts/research/fetch_history.mjs`。保存済みデータとマニフェストを利用する限り比較検証は外部通信しない。研究用CIでも再計算し、保存指標との一致を確認する。

予算計算：

```sh
node scripts/research/budget_report.mjs input.json output.json 100 1000 5000 10000
```

`input.json` は13試合の `number` と `probabilities` を含む `matches` 配列。購入に使う場合の開催回・期限・対象試合の確認は第1段階の検証を別途通す必要がある。

ブラウザーでの比較表示は `research/report.html`。研究結果JSONだけを読み、既存の公開サイトに影響しない。

## 次に検証する内容

2025年を見てパラメータを調整し同じ期間で再び成功判定しない。今後の新規期間を別途確保し、Eloの再評価、引き分け確率の校正、相手補正と休養日数、昇降格の扱いを順番に検証する。過去時点で取得できたことが確認できない負傷・天気などを混ぜない。改善が確認できなければ本番モデルは維持する。
